Расчёт и ожидаемые результаты
-----------------------------

Обозначения и расчётные зависимости
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* :math:`U_S` — напряжение питания силовой цепи.
* :math:`R_L` — сопротивление нагрузки.
* :math:`u_L(t)`, :math:`i_L(t)` — напряжение и ток нагрузки.
* :math:`u_K(t)`, :math:`i_K(t)` — напряжение и ток исследуемого ключа.
* :math:`f`, :math:`T=1/f` — частота и период управления.
* :math:`D=t_{\mathrm{cmd,on}}/T` — коэффициент заполнения команды включения.

.. Не смешивайте коэффициент заполнения и скважность q=1/D.
.. Фактическая длительность включения нагрузки может отличаться от команды.

Для резистивной нагрузки:

.. math::

   i_L(t) = \frac{u_L(t)}{R_L},
   \qquad
   P_L = \frac{1}{T}\int_0^T u_L(t)i_L(t)\,dt.

Средняя мощность потерь на исследуемом ключе в установившемся периодическом
режиме при согласованных направлениях напряжения и тока:

.. math::

   P_K = \frac{1}{T}\int_0^T u_K(t)i_K(t)\,dt.

ЗАПОЛНИТЬ: способ расчёта мощности управления по входным портам выбранной
схемы. При нескольких источниках учесть каждый из них и исключить двойной учёт.
Произведение средних напряжения и тока не заменяет среднее их произведения.

.. Здесь приведены общие определения. Формулы выбора управляющих резисторов,
.. драйвера и других деталей добавьте для конкретного устройства.
.. Если сигналы не позволяют измерить переключательные потери, укажите это.
.. Не выдавайте результат ниже разрешения приборов за точный ноль.

Опыт 3. Влияние тока нагрузки
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Задача и условия
^^^^^^^^^^^^^^^^

**Задача:** определить влияние тока нагрузки на падение напряжения,
потери, мощность нагрузки и, при измерении, нагрев.

**Изменяем:** сопротивление резистивной нагрузки.

**Сохраняем:** питание, частоту, коэффициент заполнения и параметры управления.
Фактический ток определяем измерением.

**План:** ЗАПОЛНИТЬ: набор сопротивлений, их допустимые мощности,
ожидаемые токи, время выдержки и критерии прекращения опыта.

^^^^^^^^^^^^^^^^^^^

ЗАПОЛНИТЬ: расчёт токов, падения напряжения и потерь для выбранных точек.

Порядок измерений
^^^^^^^^^^^^^^^^^

#. Изменять сопротивление нагрузки по плану, отключая питание при замене.
#. В каждой точке измерить фактические ток и напряжение нагрузки,
   напряжение на ключе, мощность управления и потери.
#. Записать переходные процессы для выбранных значений тока.
#. При измерении температуры выдержать выбранное время и записать условия.
